# EstéticaPro — Landing Page

Landing page da plataforma de gestão para estéticas automotivas, lava-rápidos e detailers.

## Estrutura

```
index.html        # página (HTML semântico, sem dependências de JS externas)
style.css         # design system + responsivo
script.js         # reveal ao rolar, menu mobile, abas do mockup, FAQ
termos.html / privacidade.html
```

## Seções

1. Hero — proposta + mockup interativo do painel
2. Problema — 4 dores
3. Funcionalidades — 8 módulos
4. Vídeo de apresentação
5. Como funciona — 4 passos
6. Antes × Depois
7. Para quem é
8. FAQ (`<details>` nativo)
9. CTA final

Todos os CTAs apontam para o WhatsApp (`wa.me/5519992255296`). Quando houver
página de cadastro, troque esses links.

## Como abrir

Abra `index.html` no navegador ou rode `python -m http.server`.
